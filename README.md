# Responsive Blog — Minimal Notlar

Can Ali Rıza Dinç tarafından HTML, CSS ve vanilla JavaScript ile geliştirilen sade ve responsive blog projesi.

## Özellikler

- Mobil, tablet ve masaüstü uyumlu
- Açık/koyu tema
- Mobil hamburger menü
- Kategori filtreleme
- Responsive yazı kartları
- Demo bülten formu
- Semantik HTML yapısı

## GitHub Pages
